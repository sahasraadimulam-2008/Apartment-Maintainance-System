# Apartment Maintenance System

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Programming Language: JavaScript
- AI: AI API integration
- Version Control: Git and GitHub

## Project Modules

1. Authentication and Authorization
2. Resident and Flat Management
3. Complaint Management
4. AI Complaint Assistant
5. Maintenance Payment Management
6. Staff Management
7. Announcements
8. Dashboard and Reports
9. Testing and Deployment

## Folder Structure

- client/: React frontend
- server/: Node.js and Express backend
- server/src/config/: Database configuration
- server/src/models/: Database models
- server/src/controllers/: Business logic
- server/src/routes/: API endpoints
- server/src/middleware/: Authentication and error handling
- server/src/services/: AI and other services
- server/tests/: Backend tests
- docs/: Project documentation

## Team Workflow

1. Each member works on their assigned module.
2. Create a separate Git branch for each feature.
3. Test the changes before submitting them.
4. Submit a pull request for review.
5. The team leader reviews and integrates the changes.
6. Do not commit passwords, API keys, or secrets.
